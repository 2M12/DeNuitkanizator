**Спасибо за интерес к проекту!** Я приветствую любые улучшения — будь то исправление бага, новая фича или улучшение документации.


## ❓ Что можно сделать

* **Сообщить об ошибке:** откройте [Issue](https://github.com/2M12/DeNuitkanizator/issues) с описанием проблемы. Приложите:
  * Версию DeNuitkanizator
  * Версию Python (если запускаете `.py`-скрипт)
  * Пример `.exe`-файла, на котором воспроизводится ошибка (если возможно)
  * Лог-файл из папки `DeNuitkanizator_Output/`
* **Предложить новую функцию:** создайте Issue с идеей и описанием, как это должно работать. Особенно приветствуются предложения по улучшению детекта Nuitka-сборок.
* **Сделать Pull Request:** форкните репозиторий, внесите изменения и отправьте PR.


## 🔀 Процесс Pull Request

1. Форкните репозиторий.
2. Создайте ветку: `feature/название` или `fix/название`.
3. Внесите изменения.
4. Протестируйте:
   * Запустите `python DeNuitkanizator.py` на тестовом `.exe`
   * Проверьте, что все артефакты извлекаются корректно
   * Убедитесь, что вывод в `summary.txt` формируется без ошибок
5. Отправьте Pull Request с описанием:
   * Что сделано
   * Ссылка на связанный Issue (если есть)
   * На чём тестировали (версия Nuitka, тип сборки - OneFile/standalone)


## ❗ Требования к коду

* Python 3.11+
* Зависимости: `pefile`, `colorama` (обязательные); `capstone`, `zstandard` (опциональные)
* Соблюдение PEP 8 (желательно, но необязательно)
* Комментарии к новым функциям и сложным участкам:
  * Что делает блок
  * Какие параметры принимает
  * Что возвращает
* Не ломать обратную совместимость с Python 3.11
* Опциональные зависимости должны оставаться опциональными - программа не должна падать при их отсутствии (используйте `try/except ImportError`)
* Тестирование перед PR обязательно


## ➡️ Приоритетные направления

* **Улучшение детекта Nuitka-сборок:** новые сигнатуры, эвристики для версий Nuitka с агрессивной LTO-оптимизацией
* **Расширение поддержки Python-версий:** добавление сигнатур для Python 3.12+
* **Улучшение извлечения байткода:** более точный поиск magic-чисел, восстановление структуры `.pyc` из фрагментов
* **Поддержка ELF/Mach-O:** анализ Nuitka-сборок под Linux и macOS
* **Улучшение дизассемблерной части:** более умный анализ точки входа, поиск вызовов Python C API (при наличии Capstone)
* **HTML-отчёт:** генерация структурированного отчёта в дополнение к `summary.txt`
* **Оптимизация скорости:** профилирование на больших файлах (100+ МБ), поиск узких мест в поиске строк и байткода
